이 책에서 얻을 수 있는 것

기획·마케팅·영업 직무에서 1주 동안 직접 AI를 써본 기록입니다. 잘된 것도, 별로였던 것도 솔직하게 담았습니다. 프롬프트를 복사해서 바로 쓸 수 있고, 각 단계에서 "이러면 잘된 것, 이러면 별로인 것" 기준도 함께 제공합니다.

다른 곳에서는 유료인 콘텐츠를 무료로 드리는 이유

AI를 일에 쓰고 싶은데 시작이 막막한 분들이 너무 많아서요. 이 한 권으로 "아, 이렇게 하면 되는구나" 감을 잡으시면, 그때부터 Caselab의 다른 콘텐츠도 도움이 될 거예요.

  1. 빈 입력칸 앞에서 머리가 하얘질 때

    AI를 켜기 전에 종이에 한 문단을 먼저 쓰는 이유

  2. 기획서 — '의도' 던지는 5단계

    문제정의 → 가설 → 검증방법 → 실행안 → 측정

  3. 경쟁사 분석 — AI가 표면만 긁는 이유

    "경쟁사 5곳 분석해줘"가 실패하는 구조

  4. 영업 보고서 — 윗사람 톤에 맞추기

    "본인 것으로 만드는 4단계" 체크리스트

  5. 고객 인터뷰 정리 — 시킬 것과 시키지 말 것

    녹취 20시간을 통째로 던지면 다 비슷해지는 이유

  6. AI가 정당화만 할 때 — 반박시키는 4가지 지시법

    약점 찾기, 반대 입장, 역사적 실패, 숨은 가정

  7. 프롬프트 모음 — 복사해서 바로 쓰기

    직무별 정리 + 상황 설명 + 예상 결과
