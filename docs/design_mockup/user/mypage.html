고객센터

회원 탈퇴는 어떻게 하나요? ▾
마이페이지 > 프로필 > 하단 "회원 탈퇴" 버튼을 눌러주세요. 탈퇴 시 모든 데이터가 삭제되며 복구할 수 없습니다.
ebook은 어떤 포맷으로 제공되나요? ▾
PDF 다운로드와 웹 전자책 뷰어 두 가지로 제공됩니다. 마이페이지 > 내 서재에서 확인할 수 있습니다.
유료 ebook 환불이 가능한가요? ▾
디지털 콘텐츠 특성상 결제 후 7일 이내, 다운로드하지 않은 경우에만 환불이 가능합니다.
뉴스레터 수신을 해지하고 싶어요. ▾
마이페이지 > 구독·결제에서 뉴스레터 수신 토글을 끄시면 즉시 해지됩니다.
콘텐츠 주제를 제안하고 싶어요. ▾
홈 하단의 "이런 거 다뤄주세요" 섹션에서 주제를 제안하거나, 1:1 문의로 남겨주세요.
