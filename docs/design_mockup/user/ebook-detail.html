목차

  1. 빈 입력칸 앞에서 머리가 하얘질 때

    AI를 켜기 전에 종이에 한 문단을 먼저 쓰는 이유. Step-0 framework.

  2. 기획서 — '의도' 던지는 5단계

    문제정의 → 가설 → 검증방법 → 실행안 → 측정. 각 단계에서 AI에게 시킬 것.

  3. 경쟁사 분석 — AI가 표면만 긁는 이유

    "경쟁사 5곳 분석해줘"가 실패하는 구조와, 깊이를 만드는 4단계.

  4. 영업 보고서 — 윗사람 톤에 맞추기

    AI 결과물을 "본인 것으로 만드는 4단계". 거래처·회사 톤·질문 대응.

  5. 고객 인터뷰 정리 — 시킬 것과 시키지 말 것

    녹취 20시간을 AI에 통째로 던지면 다 비슷해지는 이유와 분리 기준.

  6. AI가 정당화만 할 때 — 반박시키는 4가지 지시법

    약점 찾기, 반대 입장, 역사적 실패, 숨은 가정. 가설 검증에 AI를 제대로 쓰는 법.

  7. 프롬프트 모음 — 복사해서 바로 쓰기

    본문에 나온 프롬프트 전체를 직무별로 정리. 상황 설명 + 프롬프트 + 예상 결과.
