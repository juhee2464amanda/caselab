ScreenFlow

URL 한 줄로 웹사이트의 전체 화면 플로우를 통째로 캡처. 피그마로 바로 복사할 수 있는 UX 벤치마킹 도구.

유료 한국어 지원 피그마 연동
공식 사이트 방문 실전 사용기 보기
어떤 서비스인가요

레퍼런스 사이트를 한 땀 한 땀 캡처하는 시대를 끝낸다

타사 UX를 뜯어볼 때 평소엔 스크롤하면서 캡처를 반복했죠. ScreenFlow는 URL 하나만 넣으면 사이트의 전체 흐름(Depth)을 AI가 자동으로 통째로 캡처해줍니다. 첫 화면 · 스크롤 1 · 스크롤 2 · 서브 페이지까지 한 번에.

수집한 플로우는 피그마로 바로 복사할 수 있어 디자이너와 한 보드에서 비교·논의가 가능. 화면 설계·IA 분석·경쟁사 UX 벤치마킹에 들이는 단순 반복 시간을 거의 0으로 만들어주는 도구입니다.

이런 일을 할 때 가장 빛납니다

🗺️
경쟁사 UX 벤치마킹
랜딩부터 결제까지의 화면 흐름을 한 번에 캡처. 우리 페이지와 나란히 비교 가능.
🧭
IA·화면 흐름 설계
참고 사이트 3~5개의 Depth를 한 번에 가져와 정보 구조 비교.
🎨
디자이너와 협업
캡처를 피그마로 바로 복사. 노션 링크가 아니라 같은 캔버스에서 논의 가능.
📚
UI 레퍼런스 라이브러리
프로젝트별 보드에 정리해두면 다음 화면 설계에 즉시 재활용.
주요 기능

이 도구가 잘하는 것

01
URL 한 줄 → 전체 플로우 캡처
도메인 한 줄과 깊이(Depth) 옵션만 넣으면, 사이트 전반의 화면을 AI가 자동으로 따라가며 캡처.
02
피그마 자동 복사
캡처한 화면을 피그마 보드에 한 번에 붙여넣기. 정렬도 자동이라 비교가 바로 가능.
03
스크롤·서브 페이지 추적
첫 화면만이 아닌 스크롤 단계와 하위 페이지까지 따라가서 흐름 전체를 보존.
04
레퍼런스 라이브러리
캡처본을 프로젝트·태그별로 정리. 검색해서 재활용 가능.
05
한국어 인터페이스
검색·태그·라벨까지 한국어 그대로. 영문 SaaS의 진입 장벽 없음.
