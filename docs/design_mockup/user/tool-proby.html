Proby

AI 인터뷰어가 유저에게 꼬리질문까지 던지는 심층 인터뷰 도구. 1:1 인터뷰의 깊이를 설문의 속도로.

유료 한국어 지원 다국어 인터뷰
공식 사이트 방문 실전 사용기 보기
어떤 서비스인가요

인터뷰의 깊이를 설문의 속도로

단순 객관식 설문은 표면만 긁고 끝납니다. Proby는 AI 인터뷰어가 사용자의 첫 답변에 따라 꼬리질문을 자동으로 이어가, 1:1 심층 인터뷰에 가까운 답을 설문처럼 빠르게 모읍니다.

글로벌 타겟 인터뷰도 자동 번역으로 대화 가능하고, 수집된 응답을 분석해 페르소나·인사이트까지 자동 도출. 인터뷰 기획 → 진행 → 분석을 한 도구 안에서 끝낼 수 있어, 평소 며칠 걸리던 정성 리서치가 반나절로 줄어듭니다.

주요 기능

이 도구가 잘하는 것

01
꼬리질문 자동 생성
응답자가 답할 때마다 의도에 맞는 후속 질문을 AI가 즉석에서 생성. 1:1 인터뷰처럼 깊이가 쌓입니다.
02
다국어 인터뷰
응답자는 모국어로 답하고, 운영자에게는 한국어로 번역되어 도착. 글로벌 사용자 리서치의 진입 장벽이 사라짐.
03
페르소나 자동 도출
응답 패턴을 분석해 비슷한 답을 한 사용자끼리 자동 군집. 페르소나 카드로 정리되어 나옴.
04
인사이트 요약
인터뷰 N개의 핵심 인용·반복 키워드·합의·이견을 자동 정리. 리포트 1차 초안이 자동 생성.
05
링크 한 줄로 응답자 모집
인터뷰 일정 조율 없이 링크만 공유. 응답자는 원하는 시간에 AI와 대화하면 끝.
