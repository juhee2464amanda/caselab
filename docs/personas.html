2. 5명이 공유하는 AI 어려움 — 공통 페인

개별 페르소나의 직업·맥락은 다르지만 데이터에서 반복적으로 발견된 5가지 공통 신호.
공통 1
"나만 못 쓰는 것 같다"
SNS·동료·강의에서 "잘 쓰는 사람"만 보임. 본인이 못 쓰는 게 능력 문제 같아 부끄러워서 못 묻고, 못 묻으니까 더 못 쓰는 자기의심 루프.
▸ A, C가 특히 진함. B, D, E도 일정 부분 공유
공통 2
결과물이 "그럴듯하지만 쓸 수 없다"
"세련된 포장지 속 평범한 기성품" / "어디서 본 듯한 표현" / "톤이 안 맞음" — 형식은 맞는데 내 맥락·우리 회사 색깔·우리 클라이언트가 0%.
▸ B, D, E 공통 결정타. A·C도 자주 만남
공통 3
AI가 시간을 더 잡아먹는다
5분 작업이 1시간으로. 협상하고 갈아엎고 다시 시키다 결국 직접 쓰는 게 빨랐다는 결론. 학습 곡선 비용을 못 견딤.
▸ D 가장 진함. 모든 페르소나 공유
공통 4
사회적 시선 — 들켜도 안 되고 비난도 받음
"AI 티 나면 끝" + "월급 날로 먹냐" 비난 + "다들 쓰는데 나만 못 한다" 부끄러움. 결과를 내 책임으로 만들지 못하면 사용 자체 회피.
▸ D 결정타. A는 "들킬까봐" 못 묻는 형태로
공통 5
강의·콘텐츠 자체에 대한 깊은 의심
"또 그 얘기" / "결제 마지막엔 500만원" / "광고만 보고 들어가면 실망". 신뢰 자산 매우 낮음. "잘된 사례만 자랑"은 즉시 거절.
▸ C 결정타. 모든 페르소나가 어느 정도 공유

3. 페르소나별 상세 — 누구 / 페인 / 행동 / 해결할 문제

각 페르소나마다 4영역으로 정리. "해결할 문제"는 현재 행동(회피·우회·포기)에서 발견된 갭으로 도출.
A

박지현 (32세, 마케팅 기획자 5년차)

"빈 입력칸 앞에서 머리가 하얘진다 — 영상은 많이 저장했지만 내 상황에 어떻게 갖다 쓸지 모른다."

누구인지

  • 중견기업 마케팅 기획팀 5년차
  • 주 업무: 캠페인 기획서, 보고서, 시장조사 정리
  • 인스타·노션에 AI 자료 200개+ 저장, 실제 적용 거의 0
  • 회사에서 모르는 거 들킬까봐 못 물음

핵심 페인 (인용 기반)

"다들 쓰는데 나만 못 쓰는 것 같다"
"AI에게 똑똑하게 말 걸기, 생각보다 어렵다"
"혼자 갈아엎고 있다. 나 자신을 객관적으로 보고 싶은데 혼자선 어렵다"
"빈 입력칸 보면 머리가 하얘져요"

현재 행동 (어떻게 우회·회피하나)

  • 인스타 영상 200개+ 저장 → 한 번도 안 꺼냄
  • "기획서 써줘" 한 줄 시도 → 결과 실망 → 닫음
  • 구글 검색 + 선배 물어보기로 회귀
  • 새 AI 영상 봐도 "내 상황엔 안 맞을 듯"으로 끝

우리가 해결해야 할 문제

① 시작점 막힘 해소 — 빈 입력칸 앞에서 첫 한 줄을 어떻게 쓰는지의 step-0 framework
② 저장된 자료를 자기 상황에 연결 — "이 영상은 어떤 상황 / 어떤 직무 / 어떤 첫 30초"인지 명시 태깅
③ "나만 못 한다"는 외로움 해소 — "다들도 똑같이 막혔다"는 동료 신호. 운영자가 같은 페르소나임을 명시
B

이민준 (35세, 대기업 전략팀 과장)

"AI에 가설을 던지면 반박이 아니라 정당화가 돌아온다 — 신뢰가 무너졌다."

누구인지

  • 대기업 전략팀 과장. 신사업 검토·경쟁사 분석·임원 보고서
  • ChatGPT Plus 구독, 주 2~3회 (감소 추세)
  • 분석적 톤, 약간 냉소. 처음엔 좋았다가 점점 식음
  • 보안 때문에 회사 정보 못 넣음

핵심 페인 (인용 기반)

"내 의견을 검증하기보다는 정당화하는 역할을 한 셈이다"
"반박하면 맞아~~ 그러면서 말을 바꿔서 또 거기에 맞게 설명을 잘 해줘"
"세련된 포장지 속 평범한 기성품을 본 기분"
"GPT - 무슨 말이든 씨부림"

현재 행동

  • 영어 메일 다듬기·회의록 요약만 사용
  • 보고서 초안은 거의 안 시킴. 시키면 90% 갈아엎음
  • 노션 프롬프트 30개에서 멈춤 (새 시도 동력 없음)
  • 컨설팅 출신 동료 어깨너머로 배움

우리가 해결해야 할 문제

① AI 신뢰 영역 식별 — 어디서 믿고 어디서 의심해야 하는지 메타 framework
② 정당화 깨기 — 가설을 반박시키는 step별 지시법 ("이 의견의 약점 3개", "반대 입장에서 다시")
③ 실패 사례 라이브러리 — "다른 사람의 실패 사례가 사실은 제일 빨리 배우게 됨" 본인 진술. 솔직한 별로였던 사례 ≥30%

"AI 강의 단돈 3만원에 수강... 너무 실망스러운 결과물이라 제가 알아서 스토리를 짰어요"
"광고만 보고 들어가면 실망할 때 많죠. 그래서 저는 후기..."

"솔깃했지만 결국 거절했다"

현재 행동

  • 유튜브 5분짜리 → 따라했는데 본인 상황 안 맞음

  • 노션 프롬프트 100+ — 거의 안 꺼냄

① "광고 아님" 명시 — 결제 요구 0, 본문 안 어디에도 유료 강의 링크 0이 신뢰 자산
② 솔직한 실패담 비중 ≥40% — "잘된 케이스만 자랑하는 콘텐츠는 이제 못 믿어요" 본인 진술
③ 클라이언트별 "맥락 카드" framework — 한 번 세팅하면 매번 재활용. 1인 사업가의 시간 효율
D

최현수 (41세, 중소기업 영업팀장)

"팀장 보고용 — '별로네' '써먹을 게 별로 없네'"

현재 행동

  • 월 1~2회만 사용. 팀원 한 명이 옆에 있을 때만
  • 유튜브 5분 영상 좋아요 → 다시 안 봄
  • "AI 안 써. 시간 없어. 윗분들 싫어해" 다른 팀장들도 동일

우리가 해결해야 할 문제

① 진짜 5분 + 영업 직군 특화 — 본인 spec: "글 길면 안 봐요. 우리 직군 진짜 케이스"
② "본인 것으로 만드는 4단계" 메타 — 거래처 이름 + 실제 일 + 회사 톤 + 윗분 질문 대응
③ 단계 쪼개기 방법론 — "단계 쪼개야 한다" 인식만 있고 "어떻게 쪼개야 하는지" 모름. 영업 framework로 직접 시연

4. 종합 매트릭스 — 한 표로

5명을 같은 축으로 비교. 콘텐츠 spec 결정 시 직접 참조.
페르소나 결정타 워딩 현재 회피·우회 방식 해결해야 할 핵심 1가지 시간 요구 신뢰 임계
A 박지현 "다들 쓰는데 나만 못 쓰는 것 같다 / 혼자선 어렵다" 인스타 저장 200개 → 한 번도 안 꺼냄. 빈칸 앞에서 머리 하얘짐 시작점의 첫 한 줄을 어떻게 쓰는지 step-0 영상 ≤5분, 글은 OK "왜 이렇게" 미세 차이 설명
B 이민준 "정당화한다 / 그럴듯한 기성품" 영어 메일·요약만 사용. 보고서는 90% 갈아엎고 결국 직접 AI 가설 반박시키는 framework + 신뢰 영역 식별 5~10분 실패 사례 ≥30%
C 김소연 "또 결제 또 실망 / 솔깃했지만 거절" 강의 절반 후회. 노션 100+ 안 꺼냄. AI로 한 게 클라이언트한테 들킴 "광고 아님" 명시 + 실패담 ≥40% + 맥락 카드 5~10분 결제 요구 0 + 실패담
D 최현수 "보고서 써줘 → 실망 / AI 티 나면 끝" 한 번 시도 1시간 날린 후 안 씀. 팀원에게만 가끔 물음 영업 5분 framework + "본인 것으로 만드는 4단계" 반드시 ≤5분 윗사람 통과 4단계 보장
E 정다은 "단순한 건 잘 쓰는데 복잡한 건 / 의도 vs 소원" 카피는 90% AI 그대로. 캠페인·분석은 직접. 동료 관찰만 복잡 업무 step별 의도 전달 + 단계별 평가 기준 10~30분 OK 잘됨/별로 기준 명시

5. 콘텐츠 예시 후보 — 어떤 것부터 만들지 고민하기

각 카드 = 콘텐츠 1편. 페르소나 어떤 사람이 누구를 커버하는지 / 어떤 형식인지 명시. 첫 콘텐츠 선택의 기준은 (1) 광범위 커버 (2) 형식 시연 가능성 (3) 운영자 본인 자신감.
1순위 ⭐ 첫 콘텐츠 추천
"빈 입력칸 앞에서 머리가 하얘질 때 — 같이 첫 한 줄 쓰는 5단계"

6. 모든 콘텐츠가 지켜야 할 5가지 — MVP 콘텐츠 spec

1
시간 라벨 명시
읽는 데 N분 / 적용에 N분. 페르소나 D 결정타. ≤5분 라벨이 진입장벽 해소.
2
직무 태그 명시
기획·마케팅·운영 / 영업 / 1인 사업 / 전략·분석 묶음. 페르소나 D "정확히 우리 직군" 요구.

step별 "의도(intent)" 라벨
단계마다 "AI에게 전달할 의도는 X. 이게 빠지면 결과가 평범해진다" 명시. 페르소나 E 직접 진단.

"별로였던 사례" ≥30% 분량
