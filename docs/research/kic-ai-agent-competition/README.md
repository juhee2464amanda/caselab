## 2. 공모 주제 (원문)

> **[공모 주제]**
> **투자 및 금융 업무 혁신을 위한 AI Agent 개발**
>
> 참가자는 공모 주제 범위 안에서 해결할 문제를 자유롭게 정의할 수 있습니다.
>
> 주제 예시)
> - 기업 및 산업 동향을 기반으로 한 투자 리서치
> - 투자 대상 기업의 경쟁사 및 Peer Group 비교 분석
> - 내부 문서·규정 정보 검색 및 업무 자동화

**Tagline:** 투자 및 금융 업무의 혁신을 이끌 AI Agent를 기획하고, 실제 작동하는 MVP로 구현해보세요.

**[배경 및 목적] 원문**
> 한국투자공사(KIC)는 국민이 AI를 적극적으로 활용하는 문화를 확산하고, 투자·금융 현장에서의 AI 활용도를 높이기 위해 「국부펀드 KIC, AI 에이전트 공모전」을 개최합니다.
> 참가자는 금융·산업·기업 관련 다양한 데이터를 활용하여 실제 업무의 효율성과 품질을 높일 수 있는 AI Agent를 제안하고 구현하게 됩니다.
> 이번 공모전은 단순 질의응답형 챗봇을 넘어, 사용자의 목적을 이해하고 필요한 정보를 탐색·분석하며 도구를 활용해 결과물을 생성하는 Agent 기반 서비스의 실제 적용 가능성을 검증하는 데 목적이 있습니다.

**[대회 방식] 원문**
> - 예선: 참가 신청과 함께 AI Agent 기획서(PDF, 10페이지 이내)를 제출합니다. 문제 정의, 서비스 기획, Agent 설계 및 본선 기간 내 구현 가능성을 중심으로 평가합니다.
> - 본선: 예선 상위 12팀이 제안한 서비스를 기반으로 MVP를 개발하고 실행 코드, 데모 URL, 발표자료 등 최종 산출물을 제출합니다. 이후 온라인 발표와 질의응답을 통해 최종 6개 수상팀을 선정합니다.

**[참가 자격]** 누구나 참가 가능. 만 14세 미만은 참가 신청 전 dacon@dacon.io로 문의.
**[문의처]** 대회 기간 중 공식 답변은 **게시판을 통해서만** 제공.

## 5. 평가 기준

### 예선 — 전문가 70% + ELO 기반 참가팀 상호평가 30%

| 평가 항목 | 배점 | 평가 내용 |
|---|---|---|
| 문제 정의 및 주제 적합성 | 20 | 투자·금융 업무의 실제 문제를 명확하게 정의하였는가 |
| **AI Agent 구성 및 설계** | **25** | Agent 역할, Workflow, Tool/API 활용 및 자율성이 적절한가 |
| 차별성 및 창의성 | 20 | 기존 서비스 및 단순 LLM 활용 대비 차별점이 있는가 |
| 실현 가능성 | 20 | 본선 기간 내 제안 기능을 MVP로 구현할 수 있는가 |
| 활용성 및 확장성 | 15 | 실제 활용 가능성과 향후 확장성이 있는가 |

- 상호평가: 두 산출물을 비교해 더 나은 쪽에 투표 → Elo 산식으로 점수화. 최종 제출 팀 대상.
- 본인 팀 제출물은 투표 화면에 노출되지 않음. 평가 매칭은 랜덤.
- **최소 투표 횟수 미달 시 투표·득표 모두 미반영 (No Vote, No Gain)**. 최소 횟수·환산 방식은 평가 시작 전 공지 예정 (타 DACON 대회는 10표).

### 본선 — 전문가 100% (12팀 → 6팀)

| 평가 항목 | 배점 | 평가 내용 |
|---|---|---|
| 문제 해결 및 활용 가치 | 20 | 실제 문제를 효과적으로 해결하는가 |
| **AI Agent 구현 완성도** | **25** | 계획·판단·Tool/API 활용 등 의도한 기능을 안정적으로 수행하는가 |
| AI Agent 기술성 | 20 | 단순 LLM 호출이 아닌 Agent 구조와 기술적 차별성이 있는가 |
| 결과의 신뢰성 | 15 | 근거·출처 확인과 오류·환각 대응이 고려되었는가 |
| 사용성 및 실용성 | 10 | 사용 편의성과 업무 적용 가능성이 있는가 |
| 발표 및 질의응답 | 10 | 서비스·기술 설명이 명확하고 질의에 적절히 대응하는가 |

- 동점 시: ① 구현 완성도 → ② 문제 해결 및 활용 가치 → ③ 기술성
- 시연영상 제출 시 가산점

## 7. 규칙 및 유의사항

**팀 규칙**
- 개인 또는 팀(최대 5인). 동일인 중복 등록 불가.
- 팀빌딩 페이지로 구성한 경우, 제출 전 팀장이 반드시 **"팀으로 전환"** 완료.
- **최종 제출은 팀장만 가능** ('제출 완료' 버튼은 팀장에게만 활성화).

**외부 자원**
- 외부 데이터, 유료·무료 AI 모델 및 API 모두 허용.
- 데이터는 법적으로 접근 가능하고 사용 제한이 없어야 하며 저작권·개인정보보호법 준수.
- 모든 외부 자원의 출처를 기록·명시. 외부 자원을 써도 최종 제출물은 독창적이어야 함.
- **데이터셋 미제공.** 데이터 출처·수집일·라이선스·전처리 방법 반드시 기재.

**유의사항**
- 마감 이후 제출·수정 불가.
- 타 공모전 수상작, 기존 공개·상용화 결과물 그대로 제출 불가.
- 표절·저작권 침해·허위 기재·담합·평가 조작 시 평가 제외 / 본선 진출 취소 / 수상 취소.
- 운영진은 코드 실행·추가 자료(실행 환경, 모델, 데이터, API 이용 내역, 저장소 이력 등) 요청 가능.
- 제출 결과물이 발표·시연과 현저히 다르거나 필수 제출물 누락 시 평가·수상에 반영.

**Summary 페이지**
| 항목 | 안내 문구 |
|---|---|
| 서비스명 | 제안한 AI Agent 서비스명 |
| 문제·사용자 | 해결하려는 투자·금융 업무 문제와 주요 사용자 |

**① 문제 정의**
- 해결하려는 투자·금융 업무 문제와 현행 방식의 문제점 등을 구체적으로 작성합니다.

**② 서비스 제안 및 차별성**
- 제안하는 AI Agent 서비스 개요와 핵심 기능을 설명합니다.
- 사용자 입력부터 Agent 수행, 최종 결과물까지의 흐름을 제시합니다.

**③ Agent 역할 및 Workflow**
- Agent의 역할과 목표, 작업 계획, 정보 탐색·분석, 결과 생성 및 검증 흐름을 설명합니다.
- Agent가 스스로 판단·수행하는 범위와 종료 조건을 표시합니다.

**④ AI 기술·Tool/API 구성**
- 사용 모델, Agent Framework, RAG·Memory 및 검색 구조를 구체적으로 작성합니다.
- 연동할 Tool/API와 각 도구의 역할, 입력·출력 및 호출 조건을 설명합니다.
- 오류·환각 대응, 근거·출처 표시, 재시도·예외 처리 등 신뢰성 확보 방안을 포함합니다.

**⑤ 데이터 활용 계획**
- 활용 예정 데이터와 출처, 수집·갱신·전처리 방법을 작성합니다.
- 금융·기업·공시·산업·뉴스 등 외부 데이터의 활용 목적을 설명합니다.

**⑥ MVP 개발 계획**
- 본선 개발 기간 내 구현할 MVP 범위와 핵심 기능을 작성합니다.
- 개발 환경·기술 스택, 단계별 일정과 완료 기준을 제시합니다.
- 데모 시나리오, 주요 리스크와 대응 방안을 포함합니다.

**⑦ 기대효과 및 확장성**
- 기존 대비 시간·비용·품질·신뢰성 개선 효과를 작성합니다.

## 11. KIC가 처한 문제 (최근 기사 기반)

### ① 사내 AI 도입 부진 + 보안 논란 ← 공모전과 가장 직결
- **[사실]** 2026년 초 **AI혁신실** 신설, AI 회의 시스템 구축 중.
- **[사실]** 2026년 5월 사내 AI 개시 → 월 이용 **3,755건 → 798건 (-78.7%)**, 이용자 **339명 → 147명 (-56.6%)** (5월→9월).
- **[사실]** 같은 시기 직원들의 **ChatGPT 이용 월 36,881건 ≈ 사내 AI의 약 46배**.
- **[사실]** 2026년 10월 19일 국감(강민국 의원 자료): 사내 AI 핵심 모델이 **중국산** — 언어모델 알리바바 **Qwen3**, 임베딩 BAAI **BGE-M3** (BAAI는 2025년 3월 미국 상무부 수출통제 명단 등재). 모델 선정 기준에 개발사 국적·제재 여부 없음.
- **[사실]** KIC 해명: 정확성·추론·업무 적합성 등을 고려했고 **GPU 4개**라는 하드웨어 제약이 판단 근거. GPU 4→12개 증설 추진(약 9.5억 원 계약). 사내 AI는 9가지 업무 보조용으로 제한 활용.
- **[추론]** 질의응답 수준의 챗봇이라 업무에 쓸모가 적었고, 직원들은 보안상 위험한 외부 ChatGPT로 이탈.

### ② 수익률 압박
- **[사실]** 2026년 1~8월 6.31%로 2025년(13.91%)의 절반 이하. 과거 국감에서 해외 국부펀드 대비 저수익 지적.

### ③ 새 업무: 전략투자계정 (국내 직접투자)
- **[사실]** 정부 2026 하반기 경제성장전략: KIC에 **전략투자계정** 신설 → 반도체·AI 데이터센터·피지컬 AI·에너지·우주항공·양자 등 국내 전략산업에 장기 자금 공급. 외환보유액 위탁계정과 분리. 공사법 개정 후 **2027년 투자 개시 목표**.
- **[사실]** 규모는 약 20조 원(약 140억 달러) 보도가 있으나 미확정·매체별 상이.

1. **사내 AI 실패 후 해법 소싱 ★ 가장 유력** — 타임라인: AI혁신실 신설(연초) → 사내 AI 개시(5월) → 이용 급감(7~9월) → **공모전 시작(10/1)** → 국감 지적(10/19). 상금 1,500만 원으로 MVP 12개·기획서 900여 개 확보 = 저비용 외부 R&D.

3. **인재 파이프라인** — 최우수상 인턴 필기 5% 가산, IT 채용 분야 신설, 인력 유출 고민.

5. **전략투자계정 대비 국내 AI 생태계 탐색** (연결고리는 약함).

| 실현 가능성 (예선) | 20 | 거창하지만 안 돌아가는 결과물 (사내 AI의 재현) |
| 결과의 신뢰성 (본선) | 15 | AI가 지어낸 숫자로 투자 판단하는 사고 |
| 기술성 "단순 LLM 호출 X" | 20 | ChatGPT 한 번 부르는 것과 다를 바 없는 결과물 |
| 사용성 및 실용성 | 10 | 만들어 놓고 아무도 안 쓰는 상황 |
| 게시판: "실질적 판단·선택 구조" | – | 미리 짜인 경로로만 도는 파이프라인 |
| 게시판: "단순 종목 추천 지양" | – | 개인 투자 앱 |
| 게시판: 라이선스는 참가자 책임 | – | 데이터 라이선스 문제로 공공기관이 곤란해지는 일 |

### 한 문장 결론
> **"우리 사내 AI는 챗봇이라 안 쓰였다. 보안과 신뢰성을 지키면서 KIC 직원이 실제로 매일 쓰는, 결과물을 만들어 주는 Agent가 어떤 모습인지 보여 달라."**

## 13. 기획 전략 시사점

### 심사위원이 반길 것 ✅
- KIC의 **실제 업무 흐름**(리서치·딜 검토·위탁운용사 관리·보고)에 맞춘 문제 정의
- 모든 수치·주장에 **출처 인용 + 검증 단계** (환각 대응)
- **사람이 최종 확인하는 지점(human-in-the-loop)** 명시 — 책임 소재 중시
- **보안을 고려한 설계**: 내부망·온프레미스 이전 가능, 모델 교체 가능, 적은 GPU로 동작
- 결과물이 **보고서·비교표처럼 바로 쓸 수 있는 형태**
- **Agent의 판단 지점**(계획 수정, 도구 선택, 재탐색 루프)과 종료 조건을 그림으로 표현 → 예선 최대 배점(25점) 공략
- 상호평가는 빠르게 훑어보는 비교 투표 → **Summary 1장과 아키텍처 그림의 가독성**이 승부처
- 시연영상 가산점 → 본선 시 반드시 제출

### 꺼릴 것 ❌
- 일반 챗봇, 개인투자자용 종목 추천
- 출처 불명·라이선스 문제 데이터 (FRED, S&P 지수 등)
- **사용 모델의 출처·국적 언급 없음** — 국감 이슈 직후이므로 모델 선정 근거를 한 줄 넣으면 오히려 가점 요소
- 3주 안에 못 만들 거대한 범위

### Agent 방향 후보
| KIC의 문제 | Agent 방향 예시 | 평가 기준 연결 |
|---|---|---|
| 사내 AI 미사용·보안 취약 | 소형 모델로 동작, 모델 교체 가능, 근거 인용 필수 | 실현 가능성, 신뢰성 |
| 전략투자계정의 국내 분석 역량 부족 | 국내 AI·반도체 비상장사 실사 + Peer 비교 Agent | 문제 정의, 활용성 |
| 국내 위탁운용사(SMA) 확대 | 위탁운용사 성과·이상 징후 모니터링 Agent (GPIF 사례) | 차별성 |
| 이해충돌·국감 대응 | 투자 건별 이해관계·규정 자동 점검 컴플라이언스 Agent | 차별성, 실제 문제 |
| 인력 이탈·지식 단절 | 투자위원회 자료·내부 규정 근거 기반 리서치 Agent | 활용성 |

### 주의
- 기획서 "문제 정의"에 기사 수치(예: 사내 AI 이용 -78.7%, ChatGPT 46배)를 근거로 쓰면 주제 적합성에 유리. 단 국감 지적을 정면 비판하기보다 **"AI 도입 초기 기관이 공통으로 겪는 활용률 문제"**처럼 중립적으로 표현 (심사위원에 KIC 관계자 포함 가능성).
