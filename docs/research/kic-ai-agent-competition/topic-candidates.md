# KIC AI 에이전트 공모전 — 주제 후보

> 작성일: 2026-11-08 · 근거: [리서치 노트](./README.md)
> 점수는 공식 예선 배점에 맞춘 **자체 예상치**이며 실제 심사 결과와 무관합니다.

## 후보 선정 기준

리서치에서 나온 조건을 그대로 필터로 썼습니다.

1. **KIC 실제 업무 문제**와 연결되는가 (리서치 §11)
2. **Agent가 실질적으로 판단·선택**하는 지점이 있는가 (게시판 10/21 답변)
3. **라이선스가 깨끗한 공개 데이터**만으로 MVP가 가능한가 (게시판 10/21 답변, FRED·S&P 등 회피)
4. **3주(12/3~12/22)** 안에 웹 데모로 구현 가능한가
5. 근거·출처 표시와 환각 대응을 자연스럽게 넣을 수 있는가 (본선 신뢰성 15점)
6. 단순 종목 추천·개인 투자 앱이 아닌가

**라이선스 측면에서 비교적 안전한 데이터 후보** (이용약관은 사용 전 반드시 직접 재확인)
- 금융감독원 **DART OpenAPI** (국내 공시·재무제표)
- **KRX** 정보데이터시스템 / OPEN API (국내 시세·지수)
- 한국은행 **ECOS** (금리·환율·거시지표)
- 미국 **SEC EDGAR** (10-K, 10-Q, 13F 등 — 미국 정부 공개 자료)
- **국가법령정보센터 OPEN API** (법령·시행령)
- 공공기관 경영정보 공개시스템 **ALIO** (KIC 내부규정·경영공시)
- 공공데이터포털 (data.go.kr)

## 후보 1. 국내 전략산업 기업 실사·Peer 비교 Agent ★ 추천

**한 줄:** "회사 이름 하나만 주면, 경쟁사를 스스로 골라 비교하고 근거가 달린 투자 검토 메모 초안을 써 주는 Agent"

| 항목 | 내용 |
|---|---|
| 해결할 문제 | 전략투자계정(2027~)으로 KIC가 **국내 반도체·AI 기업**을 처음 직접 분석해야 함. 해외 중심 조직이라 국내 기업 분석 노하우·데이터 파이프라인이 부족. 한 건 검토에 공시·재무·업황 자료를 수작업으로 모으는 데 며칠 소요 |
| 주요 사용자 | KIC 전략투자 담당 운용역, 리서치 담당자 |
| 공모 예시 연결 | "투자 대상 기업의 경쟁사 및 Peer Group 비교 분석" — **예시와 정확히 일치** |
| 결과물 | 투자 검토 메모 초안 (사업 개요 / Peer 비교표 / 재무 추세 / 리스크 / 확인 필요 항목) — 모든 수치에 출처 링크 |

**Agent가 판단하는 지점 (Workflow)**
1. **계획:** 사용자 목적(예: "AI 반도체 설계사 A사 투자 검토")을 해석해 조사 항목을 세움
2. **Peer 선정:** 업종 코드·사업보고서 사업 내용·매출 구성을 보고 비교 대상을 **스스로 고르고, 선정 이유를 기록**
3. **지표 선택:** 업종 특성에 따라 비교 지표를 고름 (예: 팹리스는 R&D 비중·매출총이익률, 장비사는 수주잔고)
4. **탐색·재탐색:** 데이터 결측·불일치 발견 시 다른 공시(분기보고서, 정정공시)를 추가 조회
5. **검증:** 계산된 수치를 원 공시와 대조, 불일치·추정치는 "확인 필요"로 표시
6. **종료 조건:** 필수 항목 충족 + 검증 통과 시 종료, 실패 항목은 사람 검토로 넘김 (human-in-the-loop)

**Tool/데이터:** DART OpenAPI(공시·재무), KRX(시세·시가총액), ECOS(금리·환율), 계산 도구(밸류에이션 지표), 보고서 생성기

**MVP 범위 (3주):** 반도체·AI 섹터 상장사 한정 / Peer 3~5개 자동 선정 / 비교표 + 메모 PDF 출력 / 출처 링크·검증 배지

| 리스크 | 대응 |
|---|---|
| 비상장사 데이터 부족 | MVP는 상장사로 한정, 비상장사는 확장 로드맵으로 |
| 흔한 "리서치 Agent"로 보일 위험 | Peer 선정·지표 선택의 **판단 로그**를 화면에 노출해 차별화 |

## 후보 2. 투자 보고서 팩트체크·검증 Agent

**한 줄:** "보고서 초안(사람이 썼든 ChatGPT가 썼든)을 넣으면, 숫자와 주장 하나하나를 원자료와 대조해 틀린 곳을 짚어 주는 Agent"

| 항목 | 내용 |
|---|---|
| 해결할 문제 | 직원들이 사내 AI보다 외부 ChatGPT를 **46배** 더 씀(리서치 §11-①). 생성된 내용의 **환각·출처 불명 수치**가 투자 보고서에 섞일 위험. 사람이 일일이 검증하기엔 시간이 부족 |
| 주요 사용자 | 보고서 작성자, 검토자(팀장·투자위원회 간사), 리스크 관리 부서 |
| 공모 예시 연결 | "투자 리서치" + "업무 자동화" |
| 결과물 | 검증 리포트: 문장별 판정(일치 / 불일치 / 근거 없음), 정정 제안, 근거 링크 |

**Agent가 판단하는 지점**
1. 문서에서 **검증 가능한 주장(claim)을 추출**하고 유형 분류 (재무 수치 / 거시지표 / 사실 서술)
2. 주장 유형별로 **어떤 출처를 조회할지 선택** (DART, ECOS, EDGAR 등)
3. 단위·기준일·회계기간 차이를 해석해 비교 (예: 연결 vs 별도, 원 vs 억원)
4. 근거를 못 찾으면 검색어를 바꿔 **재탐색**, 끝내 못 찾으면 "근거 없음"
5. 종료: 모든 주장 판정 완료 → 리포트 생성

**Tool/데이터:** DART, ECOS, KRX, SEC EDGAR, 단위·기간 정규화 도구

**MVP 범위:** 국내 상장사 재무 수치 + 주요 거시지표(금리·환율) 검증에 한정 / 샘플 보고서 3종으로 데모

| 장점 | 약점 |
|---|---|
| 본선 **신뢰성(15)·기술성(20)**과 정면으로 맞물림. "ChatGPT를 막지 말고 안전하게 쓰게 하자"는 메시지가 독특 | 결과물이 "검증 리포트"라 화면이 덜 화려함. 문제 정의에서 46배 수치를 쓸 때 국감을 비판하는 어조가 되지 않게 주의 |

## 후보 3. 위탁운용사 모니터링 Agent

**한 줄:** "KIC가 돈을 맡긴 외부 운용사가 약속한 전략대로 운용하는지, 공개 공시로 스타일 이탈·이상 징후를 잡아 주는 Agent"

| 항목 | 내용 |
|---|---|
| 해결할 문제 | KIC는 자산 상당 부분을 외부 운용사에 위탁하고 국내 운용사 SMA 위탁도 확대 중. 소수 인력으로 다수 운용사를 감시하기 어려움 |
| 해외 사례 | 일본 GPIF는 AI로 위탁운용사 매매 데이터를 분석해 이상 징후 탐지 |
| 결과물 | 운용사별 모니터링 카드: 보유 종목 변화, 전략 이탈 경보, 집중도 리스크, 확인 질문 리스트 |

**Agent가 판단하는 지점**
1. 운용사가 공시한 전략(예: "미국 대형 가치주")을 해석해 **점검 규칙을 스스로 설계**
2. 분기별 보유 내역을 비교해 이탈 여부 판단, 원인 가설 수립
3. 이탈이 의심되면 추가 데이터(시장 지수 변화, 섹터 비중)를 조회해 **시장 요인인지 운용사 요인인지 구분**
4. 경보 등급 결정 후 담당자용 확인 질문 생성

**Tool/데이터:** SEC EDGAR **13F**(미국 운용사 분기 보유 내역, 공개), KRX, 계산 도구

**MVP 범위:** 13F 공시 운용사 5~10곳, 최근 8분기 / 대시보드 + 경보 리포트

| 장점 | 약점 |
|---|---|
| 참가자가 거의 안 떠올릴 주제 → **차별성** 높음. KIC 실제 업무와 직결 | 실제 KIC 위탁 데이터는 비공개라 13F로 대체해야 함. 금융 지식 진입장벽이 높아 기획서 설명 난이도 큼 |

## 후보 4. 투자 건 규정·이해충돌 사전점검 Agent

**한 줄:** "새 투자 건을 입력하면 관련 법령·내부규정·이해관계를 스스로 찾아 점검하고, 컴플라이언스 체크리스트를 만들어 주는 Agent"

| 항목 | 내용 |
|---|---|
| 해결할 문제 | 국내 직접투자가 시작되면 **퇴직자 재취업·이해충돌** 우려(국감 지적). 공사법·내부규정·투자 가이드라인을 건별로 대조하는 일이 수작업 |
| 공모 예시 연결 | "내부 문서·규정 정보 검색 및 업무 자동화" |
| 결과물 | 점검 리포트: 적용 조항 목록(조문 인용), 위반 의심 항목, 추가 확인 필요 사항 |

**Agent가 판단하는 지점**
1. 투자 건 성격(자산군, 국내/해외, 지분율 등)에 따라 **적용될 규정을 선별**
2. 대상 기업의 임원·주요주주를 공시에서 찾아 이해관계 후보 목록과 대조
3. 조문 해석이 애매하면 "판단 보류 + 법무 검토 요청"으로 분기

**Tool/데이터:** 국가법령정보센터 API(한국투자공사법 등), ALIO(KIC 내부규정), DART(임원·주주 현황), 이해관계자 목록은 **합성(가상) 데이터**

| 장점 | 약점 |
|---|---|
| 공공기관 심사위원에게 공감도 높음. 시의성 있음 | 이해관계 데이터가 가상이라 데모 설득력이 떨어질 수 있음. 국감 이슈를 정면으로 건드려 표현에 주의 필요 |

## 후보 5. 글로벌 이벤트 → 포트폴리오 영향 브리핑 Agent

**한 줄:** "미 연준 발표나 주요 기업 실적 같은 이벤트가 터지면, KIC형 포트폴리오에 미칠 영향을 자산군별로 분석해 한국어 브리핑을 써 주는 Agent"

| 항목 | 내용 |
|---|---|
| 해결할 문제 | 영문 자료가 넘치고 인력은 적음. TPA(통합 포트폴리오 운영) 도입으로 **자산군을 넘나드는 영향 분석** 수요 증가 |
| 결과물 | 아침 브리핑: 이벤트 요약, 자산군별 영향, 확인할 지표, 출처 |

**Agent가 판단하는 지점:** 이벤트 중요도 판정 → 영향받을 자산군 선택 → 필요한 지표 조회 → 시나리오 작성

**Tool/데이터:** 연준 성명서·EDGAR(미국 정부 공개 자료), ECOS, KRX

| 장점 | 약점 |
|---|---|
| 데모가 직관적이고 화려함 | **흔한 주제**라 차별성 점수가 낮을 위험. 뉴스 데이터 라이선스가 까다로움 |

## 추천: 후보 1 + 후보 2의 검증 레이어 결합

**"근거 검증이 내장된 국내 전략산업 실사·Peer 비교 Agent"**

- **문제 정의가 가장 강함:** 공모 예시("Peer Group 비교 분석")와 KIC의 새 업무(전략투자계정)에 정확히 맞물림.
- **차별성 보완:** 흔한 리서치 Agent로 보일 수 있다는 후보 1의 약점을, 후보 2의 **자체 팩트체크 단계**(생성한 수치를 원 공시와 재대조 → 검증 배지 표시)로 메움. 이렇게 하면 본선 신뢰성(15점)도 함께 공략할 수 있음.
- **실현 가능성:** DART·KRX·ECOS만으로 MVP 구성 가능, 라이선스 리스크 낮음, 3주 안에 상장사 한정 데모 가능.
- **보안 메시지:** "모델 교체 가능 구조 + 소형 모델로도 동작 + 출처 없는 문장은 출력 금지" 원칙을 기획서에 명시하면 국감 이슈 이후 KIC의 고민에 답하는 형태가 됨.

**다음 단계:** 확정되면 공식 양식 순서(Summary → ① 문제 정의 → ⑦ 기대효과 → 부록)대로 기획서 초안 작성.
